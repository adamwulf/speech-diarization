Speech recognition

Record, then click “Stop recording” to transcribe — or pick an audio or video file. Each new recording or file replaces the current audio, transcript, and speaker names.

Labels who spoke when. When off, new audio skips speaker detection and speaker names are hidden in the transcript and exports. Turning it back on detects speakers in the current audio if needed.

Larger models make fewer mistakes, but they download more data and transcribe more slowly. The selected model starts to load one second after you select it, and is used for the next transcription. Each model downloads only the first time; after that, it loads from the browser cache.
